## תחילת העבודה

1. **הורד והתקן.** קבל את המתקין מ-[mynarecorder.com/download](https://mynarecorder.com/download), או את הקובץ העצמאי `Myna Recorder.exe`, שרץ מכל מקום בלי התקנה. הגרסה הנוכחית היא 2.1.0, שיצאה ב-17 באוקטובר 2026.
2. **התחבר, או המשך בלי חשבון.** בלי חשבון אפשר להקליט, לערוך ולהפעיל מיד. [חשבון חינמי](https://mynarecorder.com/register) מוסיף ניסיון של 7 ימים לתכונות בתשלום ושומר אותך מחובר. התחבר או צור את חשבון Myna שלך עם **Continue with Google**.
3. **הקלט משהו, או תאר אותו.** לחץ על כפתור ההקלטה ובצע את המשימה. עם עוזר ה-AI אפשר להקליד מה שאתה רוצה ולתת לו לכתוב את המאקרו.
4. **הפעל אותו.** הפעל מחדש בכל פעם שצריך, במהירות ובמספר החזרות שתבחר.

אם Windows מציג את ההודעה "Windows protected your PC" בהפעלה הראשונה, בחר **More info** (מידע נוסף), ואז **Run anyway** (הפעל בכל זאת).
