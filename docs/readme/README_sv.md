## Vad den gör

| | |
|---|---|
| **Spela in och spela upp** | Tangentbord och mus, med din ursprungliga tajming. Spela upp från 0,25× till 10×, eller i loop. |
| **Redigera som ett läsbart skript** | Samma makro som en stegslista eller som text, synkroniserat åt båda hållen. Loopar, villkor, variabler och funktioner, med en förklaring på vanligt språk bredvid varje rad. |
| **Bildankare** | Vänta på en bild på skärmen, eller klicka på den. Makrot klarar ett flyttat fönster, en ny upplösning eller en annan dator. |
| **Läs text från skärmen** | Hämta ett ordernummer, ett belopp eller ett filnamn till en variabel. Två läsare körs på din dator; en tredje frågar AI:n. |
| **AI-assistent** | Beskriv makrot med vanliga ord och få tillbaka ett skript. Inget når din editor förrän du godkänner det. |
| **Skärmvakt** | Övervakare väntar på en bild, eller frågar AI:n något, medan ett makro körs eller på egen hand. De visar en popup, skickar meddelande till Telegram eller Discord, filmar skärmen, kör ett sparat skript eller stoppar körningen. |
| **Telegram och Discord** | Aviseringar från övervakare och från dina makron, samt styrning från en chatt: kör, pausa eller stoppa Recorder och hämta en skärmbild. |
| **Skärmvideo och skärmbilder** | Filma skärmen runt en händelse i en övervakare, med start några sekunder före. Ta skärmbilder eller spela in video från ett skript eller en snabbtangent: hela skärmen, ett fönster, ett område eller en ruta som du drar upp. |
| **Färgmatchning** | Vänta på en färg på skärmen eller klicka på den, och matcha bilder efter färg, form eller med en färgmask. |
| **Bildserie** | Fotografera ett område i några sekunder, bläddra sedan bland bilderna och beskär så många du behöver. |
| **Auto clicker** | Ett klick eller en tangent, om och om igen, upp till 1 000 gånger per sekund: vid markören, på en punkt, i en ruta eller i en sekvens av punkter som du spelar in genom att klicka på dem, i samma takt som du klickade. Jitter, spridning, hållläge, antal eller tidsgräns. |
| **Mänsklig rörelse** | Pekaren rör sig till varje klick på samma sätt som en riktig hand, i makron och i clickern. |
| **Scheduler** | Starta ett sparat makro vid ett datum och en tid du väljer, en gång eller upprepat med ett intervall. Schemalagda körningar väntar på sin tur, en efter en, medan Recorder är öppen. |
| **Timed Actions** | Tangenttryckningar, klick och pauser som upprepas med en timer, tillsammans med ett makro, clickern eller övervakarna, eller helt på egen hand. |
| **Fönsterkommandon** | Ta fram ett programs fönster, vänta på det, flytta, ändra storlek, maximera, minimera eller stäng det, hittat via dess titel. |
| **Exportera som program** | Spara ett makro som en .exe som körs på valfri Windows-dator, med sina bildbeskärningar och de lokala textläsarna inbyggda. |
| **Egna snabbtangenter** | Tangentkombinationer som öppnar ett program eller en webbplats, eller spelar upp ett makro, från valfritt program. |
| **Klippbordshistorik** | Behåll det du kopierar, fäst de objekt du återanvänder och klistra in dem med en snabbtangent. |
| **Live view** | En samlad översikt över allt som körs: makrot, övervakarna, timrarna, snabbtangenterna, schemat, klippbordet och loggen. Ordna den som du vill, eller flytta valfri ruta till ett eget fönster. |
| **Globala snabbtangenter** | <kbd>F2</kbd> för att spela in, <kbd>F4</kbd> för att köra, <kbd>F5</kbd> för att pausa och <kbd>F6</kbd> för att stoppa, från valfritt program. Kör startar det som hör till den öppna fliken: makrot, clickern, övervakarna eller Timed Actions. Varje tangent kan ändras. |

## Kom igång

1. **Ladda ner och installera.** Hämta installationsprogrammet från [mynarecorder.com/download](https://mynarecorder.com/download), eller den fristående `Myna Recorder.exe`, som körs var som helst utan installation. Den aktuella versionen är 2.1.0, släppt 17 oktober 2026.
2. **Logga in, eller fortsätt utan konto.** Utan konto kan du spela in, redigera och spela upp direkt. Ett [gratiskonto](https://mynarecorder.com/register) ger dig 7 dagars provperiod för de betalda funktionerna och håller dig inloggad. Logga in eller skapa ditt Myna-konto med **Continue with Google**.
3. **Spela in något, eller beskriv det.** Tryck på inspelning och gör uppgiften. Med AI-assistenten kan du skriva vad du vill och låta den skriva makrot.
4. **Kör det.** Spela upp det när du behöver, i den hastighet och med det antal upprepningar du väljer.

Om Windows visar ”Windows skyddade datorn” första gången du kör den väljer du **Mer information** och sedan **Kör ändå**.

## Krav

- Windows 10 eller Windows 11, 64-bitars
- På 54 språk: engelska, tyska, spanska, franska, italienska, portugisiska (Brasilien), polska, ryska, kinesiska (förenklad), japanska, koreanska, arabiska, armeniska, azerbajdzjanska, vitryska, bengaliska, bosniska, bulgariska, burmesiska, kinesiska (traditionell), kroatiska, tjeckiska, danska, nederländska, filippinska, finska, georgiska, grekiska, hebreiska, hindi, ungerska, indonesiska, kazakiska, khmer, kurdiska, lettiska, litauiska, luxemburgska, malajiska, norska, persiska, rumänska, serbiska, singalesiska, slovakiska, slovenska, svenska, thai, turkiska, ukrainska, urdu, uiguriska, uzbekiska och vietnamesiska. Ändra det när som helst i Settings, General (Inställningar, Allmänt).
- Ett 104 MB stort installationsprogram (`MynaRecorderSetup-2.1.0.exe`), eller en 103 MB stor fristående .exe som körs utan installation. Båda är digitalt signerade.
- En internetanslutning för inloggning och för AI-funktionerna. Inspelning, uppspelning, bildankare, de lokala textläsarna och auto clicker fungerar offline.
