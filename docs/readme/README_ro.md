## Ce face

| | |
|---|---|
| **Înregistrare și redare** | Tastatură și mouse, cu ritmul tău original. Redă de la 0,25× la 10×, sau în buclă. |
| **Editare ca script ușor de citit** | Aceeași macrocomandă ca listă de pași sau ca text, sincronizate în ambele sensuri. Bucle, condiții, variabile și funcții, cu o explicație în limbaj simplu lângă fiecare linie. |
| **Ancore de imagine** | Așteaptă o imagine pe ecran sau fă clic pe ea. Macrocomanda funcționează chiar dacă fereastra e mutată, rezoluția e alta sau rulează pe alt calculator. |
| **Citește text de pe ecran** | Salvează într-o variabilă un număr de comandă, un total sau un nume de fișier. Două cititoare rulează pe calculatorul tău; al treilea întreabă AI-ul. |
| **Asistent AI** | Descrie macrocomanda în limbaj simplu și primești un script înapoi. Nimic nu ajunge în editor până nu aprobi. |
| **Paznic de ecran** | Monitoarele urmăresc o imagine sau pun AI-ului o întrebare, cât timp rulează o macrocomandă sau de sine stătătoare. Afișează o fereastră de notificare, trimit mesaje pe Telegram sau Discord, filmează ecranul, rulează un script salvat sau opresc rularea. |
| **Telegram și Discord** | Alerte de la monitoare și de la macrocomenzi, plus control dintr-un chat: pornești, pui pe pauză sau oprești Recorder și primești o captură de ecran. |
| **Video de ecran și capturi** | Filmează ecranul în jurul unui eveniment al monitorului, pornind cu câteva secunde înainte. Fă capturi sau înregistrări video dintr-un script ori dintr-o tastă rapidă: întregul ecran, o fereastră, o regiune sau o casetă pe care o tragi. |
| **Potrivire de culori** | Așteaptă o culoare pe ecran sau fă clic pe ea și potrivește imagini după culoare, după formă sau printr-o mască de culoare. |
| **Rafală de decupare** | Fotografiază o zonă timp de câteva secunde, apoi parcurge imaginile și decupează câte ai nevoie. |
| **Autoclicker** | Un clic sau o tastă, din nou și din nou, până la 1.000 pe secundă: la cursor, într-un punct, într-o casetă sau printr-o secvență de puncte pe care le înregistrezi făcând clic pe ele, la ritmul în care ai dat clic. Jitter, dispersie, mod de menținere, un număr sau o limită de timp. |
| **Mișcare umanizată** | Indicatorul ajunge la fiecare clic așa cum o face o mână reală, în macrocomenzi și în autoclicker. |
| **Scheduler** | Pornește o macrocomandă salvată la o dată și oră alese, o singură dată sau repetat la un interval. Rulările programate așteaptă rândul, una după alta, cât timp Recorder este deschis. |
| **Timed Actions** | Apăsări de taste, clicuri și pauze care se repetă pe un cronometru, alături de o macrocomandă, de autoclicker sau de monitoare, ori de sine stătătoare. |
| **Comenzi pentru ferestre** | Adu în față fereastra unui program, așteapt-o, mut-o, redimensioneaz-o, maximizeaz-o, minimizeaz-o sau închide-o; fereastra este găsită după titlu. |
| **Export ca program** | Salvează o macrocomandă ca un singur .exe care rulează pe orice PC cu Windows, cu decupările de imagini și cititoarele locale de text incluse. |
| **Propriile taste rapide** | Combinații de taste care deschid un program sau un site web ori redau o macrocomandă, din orice program. |
| **Istoric Clipboard** | Păstrează ce copiezi, fixează elementele pe care le refolosești și lipește-le cu o tastă rapidă. |
| **Live view** | O singură tablă pentru tot ce rulează: macrocomanda, monitoarele, cronometrele, tastele rapide, programul, clipboard-ul și jurnalul. Aranjeaz-o cum vrei sau fă ca oricare casetă să plutească într-o fereastră proprie. |
| **Taste rapide globale** | <kbd>F2</kbd> pentru a înregistra, <kbd>F4</kbd> pentru a rula, <kbd>F5</kbd> pentru pauză și <kbd>F6</kbd> pentru oprire, din orice program. Rularea pornește ce ține de fila deschisă: macrocomanda, autoclicker-ul, monitoarele sau Timed Actions. Fiecare tastă poate fi schimbată. |

## Primii pași

1. **Descarcă și instalează.** Descarcă programul de instalare de pe [mynarecorder.com/download](https://mynarecorder.com/download), sau fișierul independent `Myna Recorder.exe`, care rulează de oriunde, fără instalare. Versiunea curentă este 2.1.0, lansată pe 17 octombrie 2026.
2. **Autentifică-te sau continuă fără cont.** Fără cont poți înregistra, edita și reda imediat. Un [cont gratuit](https://mynarecorder.com/register) adaugă o perioadă de probă de 7 zile a funcțiilor plătite și te menține autentificat. Autentifică-te sau creează-ți contul Myna cu **Continue with Google**.
3. **Înregistrează ceva sau descrie-l.** Apasă înregistrarea și execută sarcina. Cu asistentul AI, poți scrie ce vrei și lăsa asistentul să scrie macrocomanda.
4. **Rulează-l.** Redă-l oricând ai nevoie, la viteza și numărul de repetări pe care le alegi.

Dacă Windows afișează „Windows a protejat computerul” la prima rulare, alege **Informații suplimentare**, apoi **Executați oricum**.

Schimb-o oricând în Settings, General (Setări, General).
- Un program de instalare de 104 MB (`MynaRecorderSetup-2.1.0.exe`) sau un .exe independent de 103 MB, care rulează fără instalare. Ambele sunt semnate digital.
