## Qué hace

| | |
|---|---|
| **Grabar y reproducir** | Teclado y ratón, con tus tiempos originales. Reproduce de 0,25× a 10×, o en bucle. |
| **Editar como un script legible** | La misma macro como lista de pasos o como texto, sincronizados en ambos sentidos. Bucles, condiciones, variables y funciones, con una explicación en lenguaje sencillo junto a cada línea. |
| **Anclas de imagen** | Espera a que aparezca una imagen en pantalla, o haz clic en ella. La macro sigue funcionando si la ventana se mueve, cambia la resolución o se usa en otro equipo. |
| **Leer texto de la pantalla** | Guarda un número de pedido, un total o un nombre de archivo en una variable. Dos lectores de texto funcionan en tu equipo; un tercero consulta a la IA. |
| **Asistente de IA** | Describe la macro en lenguaje sencillo y recibe un script. Nada llega a tu editor hasta que lo apruebes. |
| **Vigilante de pantalla** | Los monitores buscan una imagen o hacen una pregunta a la IA mientras se ejecuta una macro o por su cuenta. Muestran una ventana emergente, envían mensajes a Telegram o Discord, graban la pantalla, ejecutan un script guardado o detienen la ejecución. |
| **Telegram y Discord** | Alertas de los monitores y de tus macros, y control desde un chat: ejecutar, pausar o detener Recorder y recibir una captura de pantalla. |
| **Vídeo de pantalla y capturas** | Graba la pantalla alrededor de un evento de un monitor, empezando unos segundos antes. Haz capturas o graba vídeo desde un script o un atajo de teclado: toda la pantalla, una ventana, una región o un recuadro que dibujas arrastrando. |
| **Coincidencia de color** | Espera a que aparezca un color en pantalla o haz clic en él, y busca imágenes por color, por forma o mediante una máscara de color. |
| **Ráfaga de recorte** | Sigue fotografiando un área durante unos segundos, luego repasa las imágenes y recorta todas las que necesites. |
| **Autoclicker** | Un clic o una tecla, una y otra vez, hasta 1.000 por segundo: en el cursor, en un punto, dentro de un recuadro o siguiendo una secuencia de puntos que grabas haciendo clic en ellos, al ritmo con el que hiciste clic. Variación aleatoria (jitter), dispersión, modo de mantener pulsado, un número de repeticiones o un límite de tiempo. |
| **Movimiento humanizado** | El puntero llega a cada clic como lo haría una mano real, tanto en las macros como en el autoclicker. |
| **Scheduler** | Inicia una macro guardada en la fecha y hora que elijas, una vez o repetida cada cierto intervalo. Las ejecuciones programadas esperan su turno, una tras otra, mientras Recorder está abierto. |
| **Timed Actions** | Pulsaciones de teclas, clics y esperas que se repiten con un temporizador, junto a una macro, el autoclicker o los monitores, o por su cuenta. |
| **Comandos de ventana** | Trae la ventana de un programa al frente, espérala, muévela, cambia su tamaño, maximízala, minimízala o ciérrala, encontrándola por su título. |
| **Exportar como programa** | Guarda una macro como un único .exe que funciona en cualquier PC con Windows, con sus recortes de imagen y los lectores de texto locales incluidos. |
| **Tus propios atajos** | Combinaciones de teclas que abren un programa o un sitio web, o ejecutan una macro, desde cualquier programa. |
| **Historial del portapapeles** | Guarda lo que copias, fija los elementos que reutilizas y pégalos con un atajo de teclado. |
| **Live view** | Un panel para todo lo que se está ejecutando: la macro, los monitores, los temporizadores, los atajos, el Scheduler, el portapapeles y el registro. Organízalo a tu gusto, o saca cualquier recuadro a una ventana propia. |
| **Atajos globales** | <kbd>F2</kbd> para grabar, <kbd>F4</kbd> para ejecutar, <kbd>F5</kbd> para pausar y <kbd>F6</kbd> para detener, desde cualquier programa. Ejecutar inicia lo que corresponda a la pestaña abierta: la macro, el autoclicker, los monitores o Timed Actions. Cada tecla se puede cambiar. |

## Primeros pasos

1. **Descarga e instala.** Obtén el instalador en [mynarecorder.com/download](https://mynarecorder.com/download), o el `Myna Recorder.exe` independiente, que funciona desde cualquier lugar sin instalarse. La versión actual es la 2.1.0, publicada el 17 de octubre de 2026.
2. **Inicia sesión, o continúa sin cuenta.** Sin cuenta puedes grabar, editar y reproducir de inmediato. Una [cuenta gratuita](https://mynarecorder.com/register) añade una prueba de 7 días de las funciones de pago y mantiene tu sesión iniciada. Inicia sesión o crea tu cuenta de Myna con **Continue with Google**.
3. **Graba algo, o descríbelo.** Pulsa grabar y realiza la tarea. Con el asistente de IA, puedes escribir lo que quieres y dejar que él escriba la macro.
4. **Ejecútala.** Reprodúcela cuando la necesites, a la velocidad y con el número de repeticiones que elijas.

Si Windows muestra “Windows protegió su PC” la primera vez que la ejecutas, elige **Más información** y luego **Ejecutar de todas formas**.

## Requisitos

- Windows 10 o Windows 11, de 64 bits
- En 54 idiomas: inglés, alemán, español, francés, italiano, portugués (Brasil), polaco, ruso, chino (simplificado), japonés, coreano, árabe, armenio, azerí, bielorruso, bengalí, bosnio, búlgaro, birmano, chino (tradicional), croata, checo, danés, neerlandés, filipino, finlandés, georgiano, griego, hebreo, hindi, húngaro, indonesio, kazajo, jemer, kurdo, letón, lituano, luxemburgués, malayo, noruego, persa, rumano, serbio, cingalés, eslovaco, esloveno, sueco, tailandés, turco, ucraniano, urdu, uigur, uzbeko y vietnamita. Cámbialo en cualquier momento en Settings, General.
- Un instalador de 104 MB (`MynaRecorderSetup-2.1.0.exe`), o un .exe independiente de 103 MB que funciona sin instalarse. Ambos están firmados digitalmente.
- Conexión a internet para iniciar sesión y para las funciones de IA. Grabar, reproducir, las anclas de imagen, los lectores de texto locales y el autoclicker funcionan sin conexión.
