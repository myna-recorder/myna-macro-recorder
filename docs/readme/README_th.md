| **แก้ไขเป็นสคริปต์ที่อ่านได้** | มาโครเดียวกันทั้งในรูปแบบรายการขั้นตอนและข้อความ ซิงก์กันทั้งสองทาง รองรับลูป เงื่อนไข ตัวแปร และฟังก์ชัน พร้อมคำอธิบายด้วยภาษาง่าย ๆ ข้างทุกบรรทัด |
| **จุดยึดด้วยภาพ** | รอภาพบนหน้าจอ หรือคลิกที่ภาพนั้น มาโครยังใช้ได้เมื่อหน้าต่างถูกย้าย ความละเอียดเปลี่ยน หรือย้ายไปใช้กับเครื่องอื่น |
| **อ่านข้อความจากหน้าจอ** | ดึงหมายเลขคำสั่งซื้อ ยอดรวม หรือชื่อไฟล์เข้าไปในตัวแปร มีตัวอ่านสองตัวทำงานบนคอมพิวเตอร์ของคุณ ตัวที่สามถาม AI |
| **ผู้ช่วย AI** | อธิบายมาโครด้วยภาษาธรรมดาแล้วรับสคริปต์กลับมา จะไม่มีอะไรเข้าสู่ตัวแก้ไขของคุณจนกว่าคุณจะอนุมัติ |
| **ตัวเฝ้าดูหน้าจอ** | ตัวเฝ้าดู (Monitors) คอยมองหาภาพ หรือถาม AI ระหว่างที่มาโครทำงานหรือทำงานเอง ตัวเฝ้าดูสามารถแสดงหน้าต่างแจ้งเตือน ส่งข้อความไป Telegram หรือ Discord บันทึกหน้าจอ รันสคริปต์ที่บันทึกไว้ หรือหยุดการทำงาน |
| **Telegram และ Discord** | แจ้งเตือนจากตัวเฝ้าดูและจากมาโครของคุณ และควบคุมผ่านแชท เช่น รัน หยุดชั่วคราว หรือหยุด Recorder และขอภาพหน้าจอ |
| **วิดีโอหน้าจอและภาพหน้าจอ** | บันทึกวิดีโอหน้าจอรอบเหตุการณ์ของตัวเฝ้าดู โดยเริ่มก่อนเหตุการณ์ไม่กี่วินาที ถ่ายภาพหน้าจอหรือบันทึกวิดีโอจากสคริปต์หรือปุ่มลัดได้ ทั้งหน้าจอทั้งหมด หน้าต่าง บริเวณที่เลือก หรือกรอบที่คุณลาก |
| **จับคู่สี** | รอสีบนหน้าจอหรือคลิกที่สีนั้น และจับคู่ภาพด้วยสี รูปร่าง หรือผ่านมาสก์สี |
| **ถ่ายต่อเนื่องเพื่อครอป** | ถ่ายภาพบริเวณหนึ่งต่อเนื่องเป็นเวลาไม่กี่วินาที แล้วเลื่อนดูภาพและครอปได้ตามต้องการ |
| **ตัวคลิกอัตโนมัติ** | คลิกหรือกดปุ่มหนึ่งครั้งซ้ำ ๆ สูงสุด 1,000 ครั้งต่อวินาที ที่ตำแหน่งเคอร์เซอร์ ที่จุดที่กำหนด ในกรอบ หรือตามลำดับจุดที่คุณบันทึกด้วยการคลิก ในจังหวะเดียวกับที่คุณคลิก มีการสุ่มเล็กน้อย การกระจาย โหมดกดค้าง และการนับจำนวนหรือจำกัดเวลา |
| **การเคลื่อนเมาส์แบบคน** | เคอร์เซอร์เคลื่อนไปยังทุกจุดที่คลิกเหมือนมือจริง ทั้งในมาโครและในตัวคลิก |
| **Scheduler (ตัวจัดตาราง)** | เริ่มมาโครที่บันทึกไว้ตามวันและเวลาที่คุณเลือก ทำครั้งเดียวหรือวนซ้ำตามช่วงเวลา การรันตามตารางจะรอคิวทีละรายการ ตราบที่ Recorder เปิดอยู่ |
| **Timed Actions (การทำงานตามเวลา)** | การกดปุ่ม การคลิก และการรอที่ทำซ้ำตามตัวจับเวลา ทำงานควบคู่กับมาโคร ตัวคลิก หรือตัวเฝ้าดู หรือทำงานเองก็ได้ |
| **คำสั่งหน้าต่าง** | นำหน้าต่างของโปรแกรมขึ้นมาข้างหน้า รอให้ปรากฏ ย้าย ปรับขนาด ขยายเต็มจอ ย่อ หรือปิด โดยค้นหาจากชื่อหน้าต่าง |
| **ส่งออกเป็นโปรแกรม** | เขียนมาโครเป็นไฟล์ .exe ไฟล์เดียวที่รันบนพีซี Windows เครื่องใดก็ได้ พร้อมภาพที่ครอปไว้และตัวอ่านข้อความในเครื่องที่ฝังมาให้ |
| **ปุ่มลัดของคุณเอง** | ชุดปุ่มลัดที่เปิดโปรแกรมหรือเว็บไซต์ หรือเล่นมาโคร จากโปรแกรมใดก็ได้ |
| **ประวัติคลิปบอร์ด** | เก็บสิ่งที่คุณคัดลอก ปักหมุดรายการที่ใช้บ่อย และวางด้วยปุ่มลัด |
| **Live view (มุมมองสด)** | กระดานเดียวสำหรับทุกอย่างที่กำลังทำงาน ได้แก่ มาโคร ตัวเฝ้าดู ตัวจับเวลา ปุ่มลัด ตาราง คลิปบอร์ด และบันทึกการทำงาน จัดเรียงตามที่คุณต้องการ หรือลอยกล่องใดก็ได้ไว้ในหน้าต่างของมันเอง |
| **ปุ่มลัดทั่วระบบ** | <kbd>F2</kbd> เพื่อบันทึก <kbd>F4</kbd> เพื่อรัน <kbd>F5</kbd> เพื่อหยุดชั่วคราว และ <kbd>F6</kbd> เพื่อหยุด ใช้ได้จากทุกโปรแกรม การรันจะเริ่มสิ่งที่แท็บที่เปิดอยู่เกี่ยวข้องด้วย ได้แก่ มาโคร ตัวคลิก ตัวเฝ้าดู หรือ Timed Actions ปุ่มลัดทุกปุ่มเปลี่ยนได้ |

## เริ่มต้นใช้งาน

1. **ดาวน์โหลดและติดตั้ง** รับตัวติดตั้งได้จาก [mynarecorder.com/download](https://mynarecorder.com/download) หรือไฟล์ `Myna Recorder.exe` แบบสแตนด์อโลน ซึ่งรันจากที่ไหนก็ได้โดยไม่ต้องติดตั้ง เวอร์ชันปัจจุบันคือ 2.1.0 เผยแพร่เมื่อ 17 ตุลาคม 2026
2. **ลงชื่อเข้าใช้ หรือดำเนินการต่อโดยไม่ใช้บัญชี** หากไม่มีบัญชี คุณสามารถบันทึก แก้ไข และเล่นซ้ำได้ทันที [บัญชีฟรี](https://mynarecorder.com/register) จะเพิ่มช่วงทดลองใช้ฟีเจอร์แบบชำระเงิน 7 วัน และช่วยให้คุณลงชื่อเข้าใช้ค้างไว้ ลงชื่อเข้าใช้หรือสร้างบัญชี Myna ของคุณด้วย **Continue with Google**
3. **บันทึกบางอย่าง หรืออธิบายมัน** กดบันทึกแล้วทำงานนั้น หรือใช้ผู้ช่วย AI พิมพ์สิ่งที่ต้องการ แล้วให้ AI เขียนมาโครให้
4. **รันมาโคร** เล่นซ้ำเมื่อคุณต้องการ ที่ความเร็วและจำนวนรอบที่คุณเลือก

หาก Windows แสดงข้อความ "Windows protected your PC" ในการรันครั้งแรก ให้เลือก **More info** แล้วจึงเลือก **Run anyway**
