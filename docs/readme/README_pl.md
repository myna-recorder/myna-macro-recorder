## Co robi

| | |
|---|---|
| **Nagrywanie i odtwarzanie** | Klawiatura i mysz, z zachowaniem oryginalnego tempa. Odtwarzanie od 0,25× do 10× albo w pętli. |
| **Edycja jako czytelny skrypt** | To samo makro jako lista kroków lub jako tekst, zsynchronizowane w obie strony. Pętle, warunki, zmienne i funkcje, z prostym wyjaśnieniem obok każdej linii. |
| **Kotwice obrazu** | Czekaj na obraz na ekranie lub kliknij go. Makro działa po przesunięciu okna, przy nowej rozdzielczości i na innym komputerze. |
| **Odczyt tekstu z ekranu** | Pobierz numer zamówienia, sumę lub nazwę pliku do zmiennej. Dwa lokalne czytniki tekstu działają na Twoim komputerze; trzeci pyta AI. |
| **Asystent AI** | Opisz makro zwykłym językiem i otrzymaj skrypt. Nic nie trafia do edytora, dopóki go nie zatwierdzisz. |
| **Strażnik ekranu** | Monitory wypatrują obrazu lub zadają pytanie AI, gdy działa makro albo samodzielnie. Wyświetlają okno powiadomienia, wysyłają wiadomość na Telegram lub Discord, nagrywają ekran, uruchamiają zapisany skrypt lub zatrzymują działanie. |
| **Telegram i Discord** | Alerty z monitorów i z Twoich makr oraz sterowanie z czatu: uruchamianie, wstrzymywanie i zatrzymywanie Recordera oraz odbieranie zrzutu ekranu. |
| **Wideo z ekranu i zrzuty ekranu** | Nagrywaj ekran wokół zdarzenia monitora, zaczynając kilka sekund wcześniej. Rób zrzuty ekranu lub nagrywaj wideo ze skryptu albo skrótu klawiszowego: cały ekran, okno, obszar lub prostokąt zaznaczony przeciągnięciem. |
| **Dopasowanie kolorów** | Czekaj na kolor na ekranie lub kliknij go, a obrazy dopasowuj według koloru, kształtu lub maski kolorów. |
| **Seria zdjęć obszaru** | Fotografuj wybrany obszar przez kilka sekund, potem przeglądaj zdjęcia i przytnij tyle, ile potrzebujesz. |
| **Auto clicker** | Jedno kliknięcie lub jeden klawisz, powtarzane w kółko, do 1 000 razy na sekundę: przy kursorze, w punkcie, w obszarze lub w sekwencji punktów, które nagrywasz, klikając je, w tempie Twoich kliknięć. Losowe odchylenie (jitter), rozrzut, tryb przytrzymania, liczba powtórzeń lub limit czasu. |
| **Naturalny ruch** | Wskaźnik dociera do każdego kliknięcia tak, jak robi to prawdziwa ręka, w makrach i w auto clickerze. |
| **Scheduler** | Uruchom zapisane makro o wybranej dacie i godzinie, jednorazowo lub powtarzane co określony czas. Zaplanowane uruchomienia czekają na swoją kolej i działają jedno po drugim, dopóki Recorder jest otwarty. |
| **Timed Actions** | Naciśnięcia klawiszy, kliknięcia i oczekiwania powtarzane według timera, obok makra, auto clickera lub monitorów, albo samodzielnie. |
| **Polecenia okien** | Przenieś okno programu na pierwszy plan, poczekaj na nie, przesuń je, zmień jego rozmiar, zmaksymalizuj, zminimalizuj lub zamknij; okno znajdziesz po tytule. |
| **Eksport jako program** | Zapisz makro jako jeden plik .exe, który działa na każdym komputerze z Windows, z wbudowanymi wycinkami obrazów i lokalnymi czytnikami tekstu. |
| **Własne skróty klawiszowe** | Kombinacje klawiszy, które otwierają program lub stronę internetową albo odtwarzają makro, z dowolnego programu. |
| **Historia schowka** | Zachowuj to, co kopiujesz, przypinaj elementy, których używasz często, i wklejaj je skrótem klawiszowym. |
| **Live view** | Jeden widok wszystkiego, co działa: makro, monitory, timery, skróty klawiszowe, Scheduler, schowek i dziennik. Ułóż go po swojemu lub przenieś dowolny panel do osobnego okna. |
| **Globalne skróty klawiszowe** | <kbd>F2</kbd> do nagrywania, <kbd>F4</kbd> do uruchamiania, <kbd>F5</kbd> do wstrzymywania i <kbd>F6</kbd> do zatrzymywania, z dowolnego programu. Uruchamianie włącza to, czego dotyczy otwarta karta: makro, auto clicker, monitory lub Timed Actions. Każdy klawisz można zmienić. |

## Pierwsze kroki

1. **Pobierz i zainstaluj.** Instalator znajdziesz na [mynarecorder.com/download](https://mynarecorder.com/download); jest też samodzielny plik `Myna Recorder.exe`, który działa z dowolnego miejsca bez instalacji. Aktualna wersja to 2.1.0, wydana 17 października 2026.
2. **Zaloguj się lub kontynuuj bez konta.** Bez konta możesz od razu nagrywać, edytować i odtwarzać. [Darmowe konto](https://mynarecorder.com/register) dodaje 7-dniowy okres próbny płatnych funkcji i utrzymuje Cię zalogowanym. Zaloguj się lub utwórz konto Myna przyciskiem **Continue with Google**.
3. **Nagraj coś albo opisz to.** Naciśnij przycisk nagrywania i wykonaj zadanie. Z asystentem AI możesz wpisać, czego chcesz, a on napisze makro.
4. **Uruchom je.** Odtwarzaj je, kiedy potrzebujesz, z prędkością i liczbą powtórzeń, które wybierzesz.

Jeśli Windows przy pierwszym uruchomieniu pokaże komunikat „System Windows ochronił ten komputer”, wybierz **Więcej informacji**, a potem **Uruchom mimo to**.

## Wymagania

- Windows 10 lub Windows 11, 64-bitowy
- W 54 językach: angielskim, niemieckim, hiszpańskim, francuskim, włoskim, portugalskim (brazylijskim), polskim, rosyjskim, chińskim (uproszczonym), japońskim, koreańskim, arabskim, ormiańskim, azerbejdżańskim, białoruskim, bengalskim, bośniackim, bułgarskim, birmańskim, chińskim (tradycyjnym), chorwackim, czeskim, duńskim, holenderskim, filipińskim, fińskim, gruzińskim, greckim, hebrajskim, hindi, węgierskim, indonezyjskim, kazachskim, khmerskim, kurdyjskim, łotewskim, litewskim, luksemburskim, malajskim, norweskim, perskim, rumuńskim, serbskim, syngaleskim, słowackim, słoweńskim, szwedzkim, tajskim, tureckim, ukraińskim, urdu, ujgurskim, uzbeckim i wietnamskim. Zmienisz to w dowolnym momencie w Settings, General.
- Instalator o wielkości 104 MB (`MynaRecorderSetup-2.1.0.exe`) lub samodzielny plik .exe o wielkości 103 MB, który działa bez instalacji. Oba są podpisane cyfrowo.
- Połączenie z internetem do logowania i funkcji AI. Nagrywanie, odtwarzanie, kotwice obrazu, lokalne czytniki tekstu i auto clicker działają offline.
