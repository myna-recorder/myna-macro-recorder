## 功能介紹

| | |
|---|---|
| **錄製與重播** | 錄下鍵盤與滑鼠操作，保留原始的操作時序。可用 0.25× 至 10× 的速度重播，或循環重複。 |
| **以易讀的腳本編輯** | 同一個巨集可以步驟清單或文字形式呈現，兩者雙向同步。支援迴圈、條件、變數與函式，每一行旁都附有白話說明。 |
| **圖片錨點** | 等待畫面上出現某張圖片，或直接點擊它。視窗移動、解析度改變或換到另一台電腦，巨集仍然有效。 |
| **讀取畫面上的文字** | 將訂單編號、總金額或檔名讀入變數。兩種讀取器在你的電腦上執行；第三種則交由 AI 處理。 |
| **AI 助理** | 用白話描述巨集，即可取得腳本。在你核准之前，任何內容都不會進入編輯器。 |
| **螢幕監控** | 監控器會監看畫面上的某張圖片，或向 AI 提問，可在巨集執行期間運作，也能單獨運作。它們可以彈出視窗、傳送訊息到 Telegram 或 Discord、錄下畫面、執行已儲存的腳本，或停止執行。 |
| **Telegram 與 Discord** | 接收監控器與巨集的通知，也能透過聊天室控制：執行、暫停或停止 Recorder，並取得螢幕截圖。 |
| **螢幕錄影與截圖** | 在監控器事件前後錄下畫面，可從事件發生前幾秒開始。可從腳本或快速鍵擷取截圖或錄影：整個螢幕、單一視窗、區域，或你拖曳出的方框。 |
| **顏色比對** | 等待畫面上出現某種顏色或點擊它，並依顏色、形狀或顏色遮罩來比對圖片。 |
| **連拍裁切** | 在數秒內持續拍攝某個區域，接著翻閱這些圖片，裁切你需要的任意張數。 |
| **自動點擊器** | 一次點擊或一個按鍵，持續重複，每秒最多 1,000 次：可在游標處、指定的點、方框內，或依你點擊錄下的點序列進行，速度與你點擊時相同。支援抖動、分散、按住模式、次數或時間上限。 |
| **擬人化移動** | 指標會像真人的手一樣移動到每個點擊位置，無論是在巨集中還是點擊器裡。 |
| **Scheduler（排程器）** | 在你選定的日期與時間啟動已儲存的巨集，可單次執行，或以固定間隔重複。排程執行會在 Recorder 開啟期間依序排隊，一個接一個執行。 |
| **Timed Actions（定時動作）** | 按鍵、點擊與等待會依計時器重複執行，可與巨集、點擊器或監控器一同運作，也能獨立執行。 |
| **視窗指令** | 依標題找到程式視窗後，將它帶到最前面、等待它出現、移動、調整大小、最大化、最小化或關閉。 |
| **匯出為程式** | 將巨集匯出為一個可在任何 Windows 電腦上執行的 .exe，並內建其圖片裁切與本機文字讀取器。 |
| **自訂快速鍵** | 自訂的按鍵組合，可在任何程式中開啟程式或網站，或播放巨集。 |
| **剪貼簿歷史記錄** | 保留你複製的內容，釘選常用的項目，並以快速鍵貼上。 |
| **Live view（即時檢視）** | 把所有執行中的項目集中在同一面板：巨集、監控器、計時器、快速鍵、排程、剪貼簿與紀錄。可依你的習慣排列，也能將任何方塊浮動成獨立視窗。 |
| **全域快速鍵** | 在任何程式中，<kbd>F2</kbd> 錄製、<kbd>F4</kbd> 執行、<kbd>F5</kbd> 暫停、<kbd>F6</kbd> 停止。「執行」會依目前開啟的分頁啟動對應項目：巨集、點擊器、監控器或 Timed Actions。每個按鍵都可以更改。 |

## 開始使用

1. **下載並安裝。** 從 [mynarecorder.com/download](https://mynarecorder.com/download) 取得安裝程式，或是免安裝、可從任何位置直接執行的獨立 `Myna Recorder.exe`。目前版本為 2.1.0，發布日期為 2026 年 10 月 17 日。
2. **登入，或不使用帳號繼續。** 不使用帳號也能立即錄製、編輯與重播。[免費帳號](https://mynarecorder.com/register)可額外取得 7 天的付費功能試用，並保持登入狀態。你可以使用 **Continue with Google** 登入，或建立 Myna 帳號。
3. **錄製一段操作，或直接描述。** 按下錄製並執行你的工作。使用 AI 助理時，你可以輸入想要的內容，讓它為你撰寫巨集。
4. **執行。** 需要時隨時重播，速度與重複次數由你選擇。

如果 Windows 第一次執行時顯示「Windows 已保護您的電腦」，請選擇 **其他資訊**，然後點選 **仍要執行**。
