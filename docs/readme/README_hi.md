2. **साइन इन करें, या बिना खाते के जारी रखें।** बिना खाते के आप तुरंत रिकॉर्ड, संपादन और रीप्ले कर सकते हैं। एक [मुफ़्त खाता](https://mynarecorder.com/register) पेड सुविधाओं का 7-दिन का ट्रायल जोड़ता है और आपको साइन इन रखता है। **Continue with Google** से साइन इन करें या अपना Myna खाता बनाएँ।
3. **कुछ रिकॉर्ड करें, या उसका वर्णन करें।** रिकॉर्ड बटन दबाएँ और काम करें। AI सहायक के साथ आप जो चाहते हैं टाइप करें और उसे मैक्रो लिखने दें।
4. **चलाएँ।** जब भी ज़रूरत हो, चुनी गई गति और दोहराव संख्या पर रीप्ले करें।
