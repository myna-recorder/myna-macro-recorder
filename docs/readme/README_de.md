**Ein Makro-Recorder für Windows, den Sie wirklich lesen und bearbeiten können.**

Zeichnen Sie auf, was Sie tun, bearbeiten Sie es als einfaches Skript und starten Sie es, wann immer Sie möchten.
Es erkennt Elemente auf dem Bildschirm anhand von Bildern und funktioniert deshalb auch dann weiter, wenn sich ein Fenster verschiebt.

## Was es kann

| | |
|---|---|
| **Aufnehmen und abspielen** | Tastatur und Maus, mit Ihrem ursprünglichen Timing. Wiedergabe von 0,25× bis 10× oder in Dauerschleife. |
| **Als lesbares Skript bearbeiten** | Dasselbe Makro als Schrittliste oder als Text, in beide Richtungen synchron. Schleifen, Bedingungen, Variablen und Funktionen, mit einer verständlichen Erklärung neben jeder Zeile. |
| **Bildanker** | Auf ein Bild auf dem Bildschirm warten oder darauf klicken. Das Makro übersteht ein verschobenes Fenster, eine neue Auflösung oder einen anderen Rechner. |
| **Text vom Bildschirm lesen** | Eine Bestellnummer, eine Summe oder einen Dateinamen in eine Variable übernehmen. Zwei Texterkenner laufen auf Ihrem Computer; ein dritter fragt die KI. |
| **KI-Assistent** | Beschreiben Sie das Makro in einfachen Worten und erhalten Sie ein Skript zurück. Nichts gelangt in Ihren Editor, bevor Sie es freigeben. |
| **Bildschirmwächter** | Monitore warten auf ein Bild oder stellen der KI eine Frage, während ein Makro läuft oder auch eigenständig. Sie blenden ein Pop-up ein, senden eine Nachricht über Telegram oder Discord, filmen den Bildschirm, starten ein gespeichertes Skript oder beenden den Lauf. |
| **Telegram und Discord** | Meldungen von Monitoren und aus Ihren Makros sowie Steuerung per Chat: Recorder starten, pausieren oder stoppen und einen Screenshot erhalten. |
| **Bildschirmvideo und Screenshots** | Den Bildschirm rund um ein Monitor-Ereignis filmen, beginnend einige Sekunden davor. Screenshots machen oder Video aufnehmen, per Skript oder Hotkey: ein ganzer Bildschirm, ein Fenster, ein Bereich oder ein Rahmen, den Sie aufziehen. |
| **Farbabgleich** | Auf eine Farbe auf dem Bildschirm warten oder sie anklicken, und Bilder nach Farbe, Form oder über eine Farbmaske abgleichen. |
| **Serienaufnahme zum Zuschneiden** | Einen Bereich einige Sekunden lang immer wieder aufnehmen, dann durch die Bilder blättern und so viele zuschneiden, wie Sie brauchen. |
| **Auto-Clicker** | Ein Klick oder eine Taste, immer wieder, bis zu 1.000 pro Sekunde: am Cursor, an einem Punkt, in einem Rahmen oder über eine Folge von Punkten, die Sie durch Anklicken aufnehmen, im Tempo Ihrer Klicks. Zufallsabweichung (Jitter), Streuung, Haltemodus, eine feste Anzahl oder ein Zeitlimit. |
| **Menschlich wirkende Bewegung** | Der Zeiger bewegt sich zu jedem Klick so, wie es eine echte Hand tut, in Makros und im Clicker. |
| **Scheduler** | Ein gespeichertes Makro zu einem Datum und einer Uhrzeit Ihrer Wahl starten, einmal oder wiederholt in einem Intervall. Geplante Läufe warten, bis sie an der Reihe sind, und laufen nacheinander, solange Recorder geöffnet ist. |
| **Timed Actions** | Tastendrücke, Klicks und Wartezeiten, die sich per Timer wiederholen, parallel zu einem Makro, zum Clicker oder zu den Monitoren oder ganz für sich. |
| **Fensterbefehle** | Das Fenster eines Programms in den Vordergrund holen, darauf warten, es verschieben, in der Größe ändern, maximieren, minimieren oder schließen; gefunden wird es über den Fenstertitel. |
| **Als Programm exportieren** | Ein Makro als eine einzige .exe ausgeben, die auf jedem Windows-PC läuft, mit eingebauten Bildausschnitten und lokalen Texterkennern. |
| **Eigene Hotkeys** | Tastenkombinationen, die ein Programm oder eine Webseite öffnen oder ein Makro abspielen, aus jedem Programm heraus. |
| **Zwischenablageverlauf** | Bewahren Sie auf, was Sie kopieren, heften Sie Einträge an, die Sie öfter brauchen, und fügen Sie sie per Hotkey ein. |
| **Live view** | Eine Übersicht für alles, was läuft: das Makro, die Monitore, die Timer, die Hotkeys, der Zeitplan, die Zwischenablage und das Protokoll. Ordnen Sie sie nach Ihren Wünschen an oder lassen Sie jede Box in einem eigenen Fenster schweben. |
| **Globale Hotkeys** | <kbd>F2</kbd> zum Aufnehmen, <kbd>F4</kbd> zum Ausführen, <kbd>F5</kbd> zum Pausieren und <kbd>F6</kbd> zum Stoppen, aus jedem Programm. Ausführen startet das, was zum geöffneten Tab gehört: das Makro, den Clicker, die Monitore oder die Timed Actions. Jede Taste lässt sich ändern. |

## Erste Schritte

1. **Herunterladen und installieren.** Holen Sie sich den Installer von [mynarecorder.com/download](https://mynarecorder.com/download) oder die eigenständige `Myna Recorder.exe`, die ohne Installation von überall läuft. Die aktuelle Version ist 2.1.0, veröffentlicht am 17. Oktober 2026.
2. **Anmelden oder ohne Konto fortfahren.** Ohne Konto können Sie sofort aufnehmen, bearbeiten und abspielen. Ein [kostenloses Konto](https://mynarecorder.com/register) bringt eine 7-tägige Testphase der kostenpflichtigen Funktionen mit und hält Sie angemeldet. Melden Sie sich an oder erstellen Sie Ihr Myna-Konto mit **Continue with Google**.
3. **Etwas aufnehmen oder beschreiben.** Starten Sie die Aufnahme und führen Sie die Aufgabe aus. Mit dem KI-Assistenten können Sie eintippen, was Sie wollen, und ihn das Makro schreiben lassen.
4. **Ausführen.** Spielen Sie es ab, wann immer Sie es brauchen, mit der Geschwindigkeit und Wiederholungszahl, die Sie wählen.

Wenn Windows beim ersten Start „Der Computer wurde durch Windows geschützt“ anzeigt, wählen Sie **Weitere Informationen** und dann **Trotzdem ausführen**.

## Anforderungen

- Windows 10 oder Windows 11, 64-Bit
- In 54 Sprachen: Englisch, Deutsch, Spanisch, Französisch, Italienisch, Portugiesisch (Brasilien), Polnisch, Russisch, Chinesisch (vereinfacht), Japanisch, Koreanisch, Arabisch, Armenisch, Aserbaidschanisch, Belarussisch, Bengalisch, Bosnisch, Bulgarisch, Birmanisch, Chinesisch (traditionell), Kroatisch, Tschechisch, Dänisch, Niederländisch, Filipino, Finnisch, Georgisch, Griechisch, Hebräisch, Hindi, Ungarisch, Indonesisch, Kasachisch, Khmer, Kurdisch, Lettisch, Litauisch, Luxemburgisch, Malaiisch, Norwegisch, Persisch, Rumänisch, Serbisch, Singhalesisch, Slowakisch, Slowenisch, Schwedisch, Thai, Türkisch, Ukrainisch, Urdu, Uigurisch, Usbekisch und Vietnamesisch. Sie können die Sprache jederzeit unter Settings, General ändern.
- Ein 104 MB großer Installer (`MynaRecorderSetup-2.1.0.exe`) oder eine 103 MB große eigenständige .exe, die ohne Installation läuft. Beide sind digital signiert.
- Eine Internetverbindung für die Anmeldung und die KI-Funktionen. Aufnehmen, Abspielen, Bildanker, die lokalen Texterkenner und der Auto-Clicker funktionieren offline.
