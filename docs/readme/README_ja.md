## 主な機能

| | |
|---|---|
| **記録と再生** | キーボードとマウスを、元のタイミングどおりに記録します。0.25倍から10倍までの速度で再生でき、繰り返し再生もできます。 |
| **読めるスクリプトとして編集** | 同じマクロを手順リストとしても、テキストとしても表示でき、双方向で同期されます。ループ、条件、変数、関数に対応し、すべての行の横に平易な説明が付きます。 |
| **画像アンカー** | 画面上の画像が現れるのを待つか、その画像をクリックします。ウィンドウを動かしても、解像度が変わっても、別のPCでも、マクロは動き続けます。 |
| **画面から文字を読み取る** | 注文番号、合計金額、ファイル名を変数に取り込めます。コンピューター上で動く2つの読み取り機能と、AIに尋ねる3つ目の機能があります。 |
| **AIアシスタント** | やりたいことを平易な言葉で説明すると、スクリプトが返ってきます。承認するまでエディターには反映されません。 |
| **画面監視** | モニターが画面上の画像を監視したり、AIに質問したりします。マクロの実行中でも、単独でも動作します。ポップアップ表示、TelegramやDiscordへの通知、画面の録画、保存したスクリプトの実行、実行の停止を行えます。 |
| **TelegramとDiscord** | モニターとマクロからの通知を送り、チャットからRecorderの実行、一時停止、停止ができます。スクリーンショットの取得も可能です。 |
| **画面の動画とスクリーンショット** | モニターのイベントの数秒前から、その前後の画面を録画します。スクリプトまたはホットキーから、画面全体、ウィンドウ、範囲、ドラッグで選んだ枠のスクリーンショットを撮ったり、動画を録画したりできます。 |
| **色の照合** | 画面上の色が現れるのを待つか、その色をクリックします。画像の一致は、色、形、または色マスクで判定できます。 |
| **連写切り抜き** | 数秒間、ある範囲を撮影し続け、あとから画像を順に見ながら、必要な分だけ切り抜けます。 |
| **自動クリッカー** | 1回のクリックまたは1つのキーを、毎秒最大1,000回まで繰り返します。カーソル位置、指定した地点、枠の中、またはクリックして記録した地点の列で、クリックしたときの間隔どおりに実行します。ジッター、ばらつき、押し続けモード、回数または時間の上限に対応します。 |
| **人間らしい動き** | マクロとクリッカーの両方で、ポインターが各クリック先へ人の手のように移動します。 |
| **Scheduler（スケジューラー）** | 保存したマクロを、指定した日時に1回、または一定の間隔で繰り返し開始します。Recorderが開いている間、予約された実行は順番待ちをして、1つずつ実行されます。 |
| **Timed Actions（タイマー動作）** | キー操作、クリック、待機を一定の間隔で繰り返します。マクロ、クリッカー、モニターと並行して、または単独で動かせます。 |
| **ウィンドウコマンド** | タイトルで見つけたプログラムのウィンドウを前面に出し、表示されるのを待ち、移動、サイズ変更、最大化、最小化、閉じる操作をします。 |
| **プログラムとして書き出し** | マクロを、どのWindows PCでも動く1つの.exeファイルとして書き出せます。画像の切り抜きとローカルの文字読み取り機能が組み込まれます。 |
| **独自のホットキー** | 任意のキーの組み合わせで、プログラムやWebサイトを開いたり、マクロを再生したりできます。どのプログラムからでも使えます。 |
| **クリップボード履歴** | コピーした内容を保存し、よく使う項目を固定して、ホットキーで貼り付けられます。 |
| **Live view（ライブ表示）** | 実行中のすべてを1つの画面にまとめます。マクロ、モニター、タイマー、ホットキー、スケジュール、クリップボード、ログです。好きな配置にでき、任意のボックスを別ウィンドウに切り離せます。 |
| **グローバルホットキー** | どのプログラムからでも、<kbd>F2</kbd>で記録、<kbd>F4</kbd>で実行、<kbd>F5</kbd>で一時停止、<kbd>F6</kbd>で停止します。実行は、開いているタブの内容を開始します。マクロ、クリッカー、モニター、またはTimed Actionsです。すべてのキーは変更できます。 |

## はじめに

1. **ダウンロードしてインストールします。** [mynarecorder.com/download](https://mynarecorder.com/download) からインストーラーを入手するか、インストール不要でどこからでも実行できる単体の `Myna Recorder.exe` を使います。現在のバージョンは2.1.0で、2026年10月17日に公開されました。
2. **サインインするか、アカウントなしで続けます。** アカウントなしでも、すぐに記録、編集、再生ができます。[無料アカウント](https://mynarecorder.com/register)を作ると、有料機能を7日間試せるトライアルが付き、サインイン状態も保たれます。**Continue with Google** でサインインするか、Mynaアカウントを作成できます。
3. **何かを記録するか、説明します。** 記録ボタンを押して作業を行います。AIアシスタントを使えば、やりたいことを入力するだけで、マクロを書いてもらえます。
4. **実行します。** 必要なときにいつでも、選んだ速度と繰り返し回数で再生できます。

初めて実行したときに「Windows によって PC が保護されました」と表示されたら、**詳細情報** を選び、次に **実行** を選んでください。
