## Що він робить

| | |
|---|---|
| **Запис і відтворення** | Клавіатура і миша з вашими початковими паузами. Відтворення від 0,25× до 10× або в циклі. |
| **Редагування у вигляді читабельного скрипта** | Той самий макрос як список кроків або як текст; зміни синхронізуються в обидва боки. Цикли, умови, змінні та функції, з поясненням простою мовою поруч із кожним рядком. |
| **Прив'язки за зображенням** | Чекайте, поки зображення з'явиться на екрані, або клацніть по ньому. Макрос працює, навіть якщо вікно перемістили, змінили роздільну здатність або запустили на іншому комп'ютері. |
| **Читання тексту з екрана** | Перенесіть номер замовлення, суму або назву файлу в змінну. Два зчитувачі працюють на вашому комп'ютері; третій звертається до ШІ. |
| **ШІ-асистент** | Опишіть макрос простою мовою і отримайте скрипт. Нічого не потрапляє у ваш редактор, доки ви не схвалите. |
| **Сторож екрана** | Монітори стежать за зображенням або ставлять запитання ШІ, поки виконується макрос або самостійно. Вони показують спливаюче вікно, надсилають повідомлення в Telegram або Discord, записують екран, запускають збережений скрипт або зупиняють виконання. |
| **Telegram і Discord** | Сповіщення від моніторів і ваших макросів, а також керування з чату: запуск, пауза або зупинка Recorder і отримання знімка екрана. |
| **Відео з екрана та знімки** | Запис екрана навколо події монітора, починаючи за кілька секунд до неї. Робіть знімки або записуйте відео зі скрипта чи гарячої клавіші: весь екран, вікно, область або рамку, яку ви виділяєте мишею. |
| **Пошук за кольором** | Чекайте, поки колір з'явиться на екрані, або клацніть по ньому, і шукайте зображення за кольором, формою або через маску кольорів. |
| **Серійна зйомка для обрізання** | Фотографуйте область кілька секунд, потім переглядайте знімки і обрізайте стільки, скільки потрібно. |
| **Автоклікер** | Одне клацання або одна клавіша знову і знову, до 1 000 разів на секунду: біля курсора, у точці, у рамці або за послідовністю точок, які ви записуєте клацанням, у тому темпі, в якому ви клацали. Джиттер, розкид, режим утримання, кількість клацань або обмеження за часом. |
| **Людиноподібний рух** | Вказівник доходить до кожного клацання так, як рухається справжня рука, в макросах і в автоклікері. |
| **Scheduler** | Запускайте збережений макрос у вибрану дату й час, один раз або з повтором через інтервал. Заплановані запуски чекають своєї черги, один за одним, поки Recorder відкритий. |
| **Timed Actions** | Натискання клавіш, клацання та паузи, які повторюються за таймером, поруч із макросом, автоклікером або моніторами, або самостійно. |
| **Команди вікон** | Виводьте вікно програми на передній план, чекайте на нього, переміщуйте, змінюйте розмір, розгортайте, згортайте або закривайте, знаходячи його за заголовком. |
| **Експорт як програма** | Збережіть макрос як один .exe, який працює на будь-якому ПК з Windows, із вбудованими фрагментами зображень і локальними зчитувачами тексту. |
| **Власні гарячі клавіші** | Комбінації клавіш, які відкривають програму чи сайт або запускають макрос, з будь-якої програми. |
| **Історія буфера обміну** | Зберігайте те, що копіюєте, закріплюйте елементи, які використовуєте часто, і вставляйте їх гарячою клавішею. |
| **Live view** | Одна панель для всього, що запущено: макрос, монітори, таймери, гарячі клавіші, розклад, буфер обміну та журнал. Розташуйте як вам зручно або винесіть будь-яку панель в окреме вікно. |
| **Глобальні гарячі клавіші** | <kbd>F2</kbd> для запису, <kbd>F4</kbd> для запуску, <kbd>F5</kbd> для паузи та <kbd>F6</kbd> для зупинки, з будь-якої програми. Запуск запускає те, що стосується відкритої вкладки: макрос, автоклікер, монітори або Timed Actions. Кожну клавішу можна змінити. |

## Перші кроки

1. **Завантажте та встановіть.** Завантажте інсталятор з [mynarecorder.com/download](https://mynarecorder.com/download) або окремий `Myna Recorder.exe`, який працює де завгодно без встановлення. Поточна версія — 2.1.0, випущена 17 жовтня 2026 року.
2. **Увійдіть або продовжте без облікового запису.** Без облікового запису можна одразу записувати, редагувати й відтворювати. [Безкоштовний обліковий запис](https://mynarecorder.com/register) додає 7-денний пробний період платних функцій і залишає вас у системі. Увійдіть або створіть свій обліковий запис Myna за допомогою **Continue with Google**.
3. **Запишіть щось або опишіть це.** Натисніть запис і виконайте завдання. За допомогою ШІ-асистента можна ввести, що потрібно, і дозволити йому написати макрос.
4. **Запустіть.** Відтворіть його, коли потрібно, зі швидкістю та кількістю повторів, які ви обираєте.

Якщо Windows показує «Windows захистила ваш ПК» під час першого запуску, виберіть **Додаткові відомості**, а потім **Все одно запустити**.
