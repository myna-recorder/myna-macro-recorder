## ما الذي يفعله

| | |
|---|---|
| **التسجيل وإعادة التشغيل** | لوحة المفاتيح والفأرة، بتوقيتك الأصلي. أعِد التشغيل بسرعة من 0.25× إلى 10×، أو كرّره بشكل متواصل. |
| **حرّره كسكربت مقروء** | الماكرو نفسه كقائمة خطوات أو كنص، ويبقيان متزامنين في الاتجاهين. حلقات وشروط ومتغيرات ودوال، مع شرح بلغة بسيطة بجوار كل سطر. |
| **مراسي الصور** | انتظر صورة على الشاشة أو انقر عليها. يستمر الماكرو في العمل رغم نقل النافذة أو تغيّر دقة الشاشة أو على جهاز آخر. |
| **قراءة النص من الشاشة** | اسحب رقم طلب أو مبلغاً إجمالياً أو اسم ملف إلى متغير. يعمل قارئان على حاسوبك، والثالث يسأل الذكاء الاصطناعي. |
| **مساعد الذكاء الاصطناعي** | صف الماكرو بلغة بسيطة واحصل على سكربت. لا يصل أي شيء إلى المحرر قبل أن توافق عليه. |
| **حارس الشاشة** | تراقب المراقبات (Monitors) صورة معيّنة، أو تسأل الذكاء الاصطناعي سؤالاً، أثناء تشغيل ماكرو أو بشكل مستقل. تظهر نافذة منبثقة، أو ترسل رسالة إلى Telegram أو Discord، أو تصوّر الشاشة، أو تشغّل سكربتاً محفوظاً، أو توقف التشغيل. |
| **Telegram و Discord** | تنبيهات من المراقبات ومن ماكرواتك، والتحكم من محادثة: تشغيل Recorder أو إيقافه مؤقتاً أو إيقافه، والحصول على لقطة شاشة. |
| **فيديو الشاشة ولقطاتها** | صوّر الشاشة حول حدث مراقبة، بدءاً من بضع ثوانٍ قبله. التقط لقطات أو سجّل فيديواً من سكربت أو اختصار: شاشة كاملة، أو نافذة، أو منطقة، أو مربع تسحبه. |
| **مطابقة الألوان** | انتظر لوناً على الشاشة أو انقر عليه، وطابق الصور حسب اللون أو الشكل أو عبر قناع لوني. |
| **التقاط متتابع للاقتصاص** | التقط صوراً متتابعة لمنطقة لبضع ثوانٍ، ثم تصفّح الصور واقتصّ منها ما تحتاجه. |
| **النقر التلقائي** | نقرة واحدة أو ضغطة مفتاح واحدة، تتكرر مراراً، حتى 1,000 مرة في الثانية: عند المؤشر، أو عند نقطة، أو داخل مربع، أو عبر تسلسل من النقاط تسجّلها بالنقر عليها، بالإيقاع الذي نقرت به. تشويش (Jitter)، وتشتيت (Scatter)، ووضع الضغط المستمر (Hold)، وعدد أو حد زمني. |
| **حركة بشرية** | ينتقل المؤشر إلى كل نقرة كما تفعل اليد البشرية، في الماكروات وفي النقر التلقائي. |
| **Scheduler** | ابدأ ماكرو محفوظاً في تاريخ ووقت تختارهما، مرة واحدة أو بتكرار على فترات. تنتظر عمليات التشغيل المجدولة دورها، واحدة تلو الأخرى، طالما Recorder مفتوح. |
| **Timed Actions** | ضغطات مفاتيح ونقرات وانتظارات تتكرر على مؤقت، إلى جانب ماكرو أو النقر التلقائي أو المراقبات، أو بشكل مستقل. |
| **أوامر النوافذ** | أحضر نافذة برنامج إلى الأمام، وانتظرها، وحرّكها، وغيّر حجمها، وكبّرها، وصغّرها، أو أغلقها، بعد العثور عليها بعنوانها. |
| **التصدير كبرنامج** | صدّر الماكرو كملف .exe واحد يعمل على أي جهاز Windows، مع مقتطعات الصور وقارئات النص المحلية مضمّنة فيه. |
| **اختصاراتك الخاصة** | مجموعات مفاتيح تفتح برنامجاً أو موقعاً، أو تشغّل ماكرو، من أي برنامج. |
| **سجل الحافظة** | احتفظ بما تنسخه، وثبّت العناصر التي تعيد استخدامها، والصقها بالاختصار. |
| **Live view** | لوحة واحدة لكل ما يعمل: الماكرو والمراقبات والمؤقتات والاختصارات والجدول والحافظة والسجل. رتّبها كما تريد، أو اجعل أي مربع عائماً في نافذة خاصة به. |
| **اختصارات عامة** | <kbd>F2</kbd> للتسجيل، و<kbd>F4</kbd> للتشغيل، و<kbd>F5</kbd> للإيقاف المؤقت، و<kbd>F6</kbd> للإيقاف، من أي برنامج. يبدأ Run ما يتعلق به التبويب المفتوح: الماكرو أو النقر التلقائي أو المراقبات أو Timed Actions. كل مفتاح قابل للتغيير. |

## البداية

1. **نزّل وثبّت.** احصل على المثبّت من [mynarecorder.com/download](https://mynarecorder.com/download)، أو على الملف المستقل `Myna Recorder.exe` الذي يعمل من أي مكان دون تثبيت. الإصدار الحالي هو 2.1.0، وقد صدر في 17 أكتوبر 2026.
2. **سجّل الدخول، أو تابع دون حساب.** دون حساب يمكنك التسجيل والتحرير والتشغيل فوراً. يضيف [حساب مجاني](https://mynarecorder.com/register) تجربة 7 أيام للميزات المدفوعة، ويُبقيك مسجّل الدخول. سجّل الدخول أو أنشئ حساب Myna بزر **Continue with Google**.
3. **سجّل شيئاً، أو صِفه.** اضغط التسجيل ونفّذ المهمة. مع مساعد الذكاء الاصطناعي، اكتب ما تريده ودعه يكتب الماكرو.
4. **شغّله.** أعِد تشغيله متى احتجت، بالسرعة وعدد التكرارات اللذين تختارهما.

إذا عرض Windows الرسالة "Windows protected your PC" عند أول تشغيل، فاختر **More info** ثم **Run anyway**.
