## 주요 기능

| | |
|---|---|
| **녹화 및 재생** | 키보드와 마우스를 원래 타이밍 그대로 기록합니다. 0.25배에서 10배까지 재생하거나 반복 재생할 수 있습니다. |
| **읽기 쉬운 스크립트로 편집** | 같은 매크로를 단계 목록이나 텍스트로 보며, 두 방식이 양방향으로 동기화됩니다. 반복, 조건, 변수, 함수를 지원하고 모든 줄 옆에 쉬운 말로 된 설명이 함께 표시됩니다. |
| **이미지 앵커** | 화면에 이미지가 나타날 때까지 기다리거나 그 이미지를 클릭합니다. 창을 옮기거나, 해상도를 바꾸거나, 다른 PC에서 실행해도 매크로가 작동합니다. |
| **화면의 텍스트 읽기** | 주문 번호, 합계 금액, 파일 이름을 변수에 가져옵니다. 두 가지 읽기 기능은 내 컴퓨터에서 실행되고, 세 번째는 AI에게 묻습니다. |
| **AI 도우미** | 원하는 매크로를 쉬운 말로 설명하면 스크립트를 만들어 줍니다. 승인하기 전에는 편집기에 아무것도 반영되지 않습니다. |
| **화면 감시** | 모니터는 이미지를 감시하거나 AI에게 질문하며, 매크로가 실행되는 동안에도, 단독으로도 동작합니다. 팝업을 띄우고, Telegram 또는 Discord로 메시지를 보내고, 화면을 녹화하고, 저장된 스크립트를 실행하거나, 실행을 중지할 수 있습니다. |
| **Telegram 및 Discord** | 모니터와 매크로에서 알림을 보내고, 채팅으로 Recorder를 실행, 일시 정지, 중지하거나 스크린샷을 받을 수 있습니다. |
| **화면 영상과 스크린샷** | 모니터 이벤트 몇 초 전부터 화면을 녹화합니다. 스크립트나 단축키로 스크린샷을 찍거나 영상을 녹화할 수 있습니다. 전체 화면, 창, 영역, 드래그로 지정한 상자를 대상으로 할 수 있습니다. |
| **색상 일치** | 화면에서 색상이 나타날 때까지 기다리거나 그 색을 클릭합니다. 이미지를 색상, 모양 또는 색상 마스크로 일치시킬 수 있습니다. |
| **연속 촬영 후 자르기** | 몇 초 동안 한 영역을 계속 촬영한 다음 이미지를 넘겨 보며 필요한 만큼 잘라냅니다. |
| **자동 클리커** | 한 번의 클릭 또는 한 개의 키를 초당 최대 1,000회까지 반복합니다. 커서 위치, 지정한 지점, 상자 안, 또는 클릭으로 기록한 지점 순서대로 클릭할 수 있으며, 클릭한 속도를 그대로 따릅니다. 지터, 분산, 누르고 있기 모드, 횟수 또는 시간 제한을 지원합니다. |
| **사람 같은 포인터 움직임** | 매크로와 클리커 모두에서 포인터가 실제 손처럼 각 클릭 지점까지 이동합니다. |
| **Scheduler(스케줄러)** | 저장한 매크로를 원하는 날짜와 시간에 한 번 또는 일정 간격으로 반복해서 시작합니다. Recorder가 열려 있는 동안 예약된 실행은 순서대로 차례를 기다립니다. |
| **Timed Actions(타이머 동작)** | 키 입력, 클릭, 대기를 타이머에 따라 반복합니다. 매크로, 클리커, 모니터와 함께 실행하거나 단독으로 실행할 수 있습니다. |
| **창 명령** | 제목으로 찾은 프로그램 창을 앞으로 가져오고, 기다리고, 이동, 크기 조절, 최대화, 최소화 또는 닫습니다. |
| **프로그램으로 내보내기** | 매크로를 Windows PC 어디서나 실행되는 .exe 파일 하나로 만듭니다. 이미지 자르기와 로컬 텍스트 읽기 기능이 포함됩니다. |
| **나만의 단축키** | 어떤 프로그램에서든 프로그램이나 웹사이트를 열거나 매크로를 실행하는 키 조합을 설정합니다. |
| **클립보드 기록** | 복사한 내용을 저장하고, 자주 쓰는 항목은 고정해 단축키로 붙여 넣습니다. |
| **Live view(실시간 보기)** | 실행 중인 매크로, 모니터, 타이머, 단축키, 스케줄, 클립보드, 로그를 한 화면에 모아 보여 줍니다. 원하는 대로 배치하거나 각 상자를 별도의 창으로 띄울 수 있습니다. |
| **전역 단축키** | 어떤 프로그램에서든 <kbd>F2</kbd>로 녹화, <kbd>F4</kbd>로 실행, <kbd>F5</kbd>로 일시 정지, <kbd>F6</kbd>로 중지합니다. 실행 키는 현재 열린 탭에 맞춰 매크로, 클리커, 모니터 또는 Timed Actions를 시작합니다. 모든 키는 변경할 수 있습니다. |

## 시작하기

1. **다운로드하고 설치합니다.** [mynarecorder.com/download](https://mynarecorder.com/download)에서 설치 파일을 받거나, 설치 없이 어디서나 실행되는 단독 `Myna Recorder.exe`를 받으세요. 현재 버전은 2.1.0이며 2026년 10월 17일에 출시되었습니다.
2. **로그인하거나 계정 없이 계속합니다.** 계정이 없어도 바로 녹화, 편집, 재생을 할 수 있습니다. [무료 계정](https://mynarecorder.com/register)을 만들면 유료 기능을 7일 동안 체험할 수 있고 로그인 상태가 유지됩니다. **Continue with Google**로 로그인하거나 Myna 계정을 만들 수 있습니다.
3. **녹화하거나 설명하세요.** 녹화를 누르고 작업을 수행하세요. AI 도우미를 사용하면 원하는 작업을 입력하고 매크로를 작성하게 할 수 있습니다.
4. **실행하세요.** 원하는 속도와 반복 횟수로 언제든 다시 재생할 수 있습니다.

처음 실행할 때 "Windows에서 PC를 보호했습니다" 메시지가 나오면 **추가 정보**를 선택한 다음 **실행**을 선택하세요.
